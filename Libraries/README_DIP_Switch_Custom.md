# Custom 4-position DIP switch footprint

Footprint:

`DIP_Switch_THT:SW_DIP_SPSTx04_Custom_11.4x9.8mm`

Assumed geometry from the measured part:

- body: 11.4 x 9.8 mm
- 8 through-hole pins
- 4 pins per row
- pitch in each row: 2.54 mm
- distance between row centers: 8.0 mm
- measured outer pin pattern: approximately 7.9 x 8.3 mm
- drill: 0.8 mm

Pin numbering follows the normal DIP convention:

```text
1  2  3  4
8  7  6  5
```

The footprint is based on the dimensions supplied by the user. Print it at 1:1 and place the physical switch on the printout before ordering the PCB.
